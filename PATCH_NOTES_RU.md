## Проверка и ограничения доказанности

**Сборка .NET и запуск xUnit здесь не выполнены.** В рабочей среде отсутствует .NET SDK; попытки получить SDK не завершились успешно. Нельзя считать этот ZIP скомпилированным, прошедшим CI или проверенным на живом AD.

Выполнены проверка изменений на ошибки whitespace, лексическая проверка и баланс разделителей в изменённых C#-файлах, проверка XML файлов проектов и существования ссылок ProjectReference, синтаксическая проверка Bash-скрипта, проверка целостности итогового ZIP. Лексическая проверка **не является** компиляцией или проверкой типов. Подробности: `validation/static-checks.json` и `validation/build-attempt.txt`.

Новый файл `tests/DogfighterAD.Core.Tests/ReviewFollowupRegressionTests.cs` содержит **18 тестовых методов и 32 сценария** с учётом InlineData. Они добавлены к тестам, уже имевшимся в выгрузке. Эти 32 сценария не запускались здесь.

| F06, writer/readback budgets | Дополнительно исправлено | Общие настройки writer и reader/readback; CLI --max-snapshot-mib 1..1024. Неизвестные поля — MetadataOnly; явно чувствительные ключи — Redacted. Это политика минимизации данных, не универсальное обнаружение всех секретов, в том числе помещённых в имена/метаданные. |

Превышение бюджета даёт capacity-exhausted вместо запуска замены поверх зависшей задачи. CTS не уничтожается, пока им пользуется задача. Native LDAP setup budget удерживается также до завершения очистки заброшенного соединения. Неотменяемый native вызов всё ещё может жить после таймаута; для абсолютного прекращения нужен отдельный процесс LDAP или перезапуск хост-процесса. |

**Итого:** исправлены дополнительные ошибки и сохранены защитные изменения выгрузки. Не заявляется, что F12 превратился в принудительно отменяемый native I/O или что default Registry.pol values полностью поддержаны. Ошибку/Partial нельзя трактовать как отсутствие риска в AD.

## Дополнительные изменения относительно входной выгрузки

- Общий бюджет физических collector tasks — 32 на процесс. Внутри одного сканирования — не более MaxConcurrency фактически незавершённых задач. Native setup budget — 16; это отдельное ограничение.
- Отмена проверяется перед публикацией нового output. Неуспешная запись оставляет прежний output неизменным и удаляет временный файл.
- CLI выводит стабильный код DogadArtifactException, не произвольный текст входного артефакта.
- Старый тест `Read_UnexpectedEntryIsRejected` явно допускает три записи по count-budget, чтобы проверять именно запрет неожиданного имени. Отдельные тесты продолжают проверять жёсткий count-budget; проверка не отключена в production.
- CLI informational version: `0.1.0-review-fix` для различения новых запусков и старого dev build.

## Совместимость

Сохранены .NET 10, архитектура read-only, существующий SYSVOL worker и текущая schema 2 из входной выгрузки. Новых NuGet-зависимостей не добавлено.

Reader работает с целым ZIP-артефактом. Для seekable stream обязательна Position=0; writer ожидает пустой stream. ZIP64, многодисковые и зашифрованные ZIP не поддерживаются. CLI ограничен 1..1024 МиБ JSON; дополнительные 64 МиБ резервируются для container budget. По умолчанию остаётся 512 МиБ JSON. Бюджет central directory — 64 КиБ. Такие ограничения намеренные, а не гарантии общей RAM или производительности.

Формат контейнера остаётся v1; схема снимка — v2. Старые schema 1 отвергаются существующей политикой совместимости, а не молча объявляются поддерживающими порядок ACE. Потоковая запись ZIP может отличаться по служебным ZIP-заголовкам от старого writer, но canonical JSON и повторная запись одним и тем же writer должны оставаться детерминированными; это покрывается существующим тестом round-trip, который требуется запустить.


```powershell

```

Эквивалентные команды, используемые существующим CI проекта:

```sh

dotnet build tests/DogfighterAD.Core.Tests/DogfighterAD.Core.Tests.csproj --configuration Release --no-restore
dotnet run --project tests/DogfighterAD.Core.Tests/DogfighterAD.Core.Tests.csproj --configuration Release --no-build
```

Используется исполняемый xUnit v3 / Microsoft Testing Platform runner. Инструкция не полагается на `dotnet test --filter`, который не был проверен для конфигурации этого проекта.

## CLI

```sh
dogfighter scan --target dc.example.test --profile audit-full --output audit.dogad --ldaps --max-snapshot-mib 768
dogfighter inspect --snapshot audit.dogad --max-snapshot-mib 768
```

Для файлов больше стандартного лимита один и тот же бюджет нужно указать и при scan, и при inspect. Увеличение лимита допускает большее потребление памяти. Пароль не передаётся аргументом командной строки.

Перед использованием в реальном аудите нужны зелёная сборка/тесты на Windows и Linux и стендовые проверки: крупная группа с range retrieval, GPO с десятками файлов, отказ доступа/поздний сбой SYSVOL, обязательный LDAP signing, доверенный/недоверенный LDAPS-сертификат и таймауты. Здесь эти проверки не проводились.
